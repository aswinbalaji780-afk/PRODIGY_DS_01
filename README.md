# PRODIGY_DS_TASK01

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Titanic dataset and visualize the distribution of categorical and continuous variables using histograms and bar charts.

---

## Dataset Used

* Titanic Dataset
* Source: Kaggle

---

## Tools and Libraries Used

* Python
* Pandas
* Matplotlib
* Seaborn
* VS Code
* Jupyter Notebook

---

## Tasks Performed

* Loaded and explored the dataset
* Checked missing values
* Cleaned the Age column using median values
* Created histogram for age distribution
* Created bar chart for gender distribution
* Analyzed passenger demographic patterns

---

## Visualizations Created

### 1. Age Distribution Histogram

* Shows distribution of passenger ages
* Helps identify common age groups and spread of data

### 2. Gender Distribution Bar Chart

* Compares male and female passenger counts
* Helps identify categorical imbalance

---

## Key Insights

* Most passengers were between 20–40 years old.
* The age distribution is slightly right-skewed.
* Male passengers significantly outnumbered female passengers.
* The dataset shows demographic imbalance among passengers.

---

## Conclusion

This project helped in understanding the basics of Exploratory Data Analysis (EDA), data cleaning, and data visualization using Python libraries. The analysis provided meaningful insights into passenger demographics from the Titanic dataset.
